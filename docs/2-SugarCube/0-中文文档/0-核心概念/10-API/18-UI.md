# UI API_界面API

提供内置对话框的打开与 UI 更新。（`UI` 是「界面工具」——弹窗、存档、设置、重启都一键搞定。）

### 方法

#### UI.alert(message [, options [, closeFn]])

打开内置警告对话框，向玩家显示给定消息。

```javascript
UI.alert("You smell of elderberries!");
```

#### UI.restart([options [, closeFn]])

打开内置重启对话框，提示玩家重启故事。

```javascript
UI.restart();
```

#### UI.saves([options [, closeFn]])

打开内置存档对话框。

```javascript
UI.saves();
```

#### UI.settings([options [, closeFn]])

打开内置设置对话框（内容来自 `Setting` API）。

```javascript
UI.settings();
```

#### UI.update()

触发 `:uiupdate` 事件，更新内置 UI 的动态更新部分（如 `StoryCaption`、`StoryMenu` 等代码段落填充的部分）。段落导航时自动调用。

```javascript
UI.update();
```

> **警告**：除主段落显示外，*所有*动态更新的内置 UI 部分都会被更新，建议谨慎使用。若只需在段落导航外更新部分区域，应只更新需要的具体区域，而非整个 UI。

#### UI.jumpto([options [, closeFn]])（已废弃）

> **已废弃**：此方法已废弃，不应再使用。

#### UI.share([options [, closeFn]])（已废弃）
