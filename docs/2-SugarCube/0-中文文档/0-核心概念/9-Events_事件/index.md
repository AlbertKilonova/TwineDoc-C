# Events Introduction_事件介绍

事件是被发送（又称：触发、派发）的消息，用于通知代码某事已经发生，从玩家交互到自动化事件。每个事件由一个对象表示，该对象具有可用于获取有关所发生事情的额外信息的属性。

本节提供 SugarCube 特定事件的列表，这些事件在故事运行期间的各个时间点被触发。（事件是「广播站」——发生了什么，广而告之。）

> **参见**：有关标准浏览器/DOM 事件，请参阅 MDN 上的事件参考。
