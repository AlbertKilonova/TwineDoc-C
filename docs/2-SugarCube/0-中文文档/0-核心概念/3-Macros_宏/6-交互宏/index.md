# Interactive Macros Warning_交互宏警告

交互宏既是异步的，又需要玩家的交互。因此，有一些潜在的陷阱需要考虑：

1. 如果你打算在循环中使用交互宏，由于它们的异步性质，你很可能需要使用 `<<capture>>` 宏。
2. 刷新页面或重新访问段落可能无法恢复某些交互宏的状态，因此建议你仅在不会出现此问题、或可以绕过此问题的情况下使用它们。（交互宏是「异步玩家」——你得等它，它不等你。）
