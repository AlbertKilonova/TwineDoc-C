# Redo_触发刷新

让一个或多个 `<<do>>` 宏更新其内容。（`<<redo>>` 是「刷新广播站」——一声令下，对应的 `<<do>>` 屏幕集体更新。）

### 语法

```SugarCube
<<redo [tags]>>
```

### 参数

* **`tags`**：（可选）以空格分隔的标签列表，对应要发送更新命令的带标签 `<<do>>` 宏。若省略，则向所有 `<<do>>` 宏发送更新命令。

### 示例

示例请参阅 `<<do>>` 宏。
