# Hyphen_转义输出

输出给定表达式结果的字符串表示。此宏在功能上与 `<<print>>` 完全一致，唯一区别是它还会对输出中的 HTML 特殊字符进行编码。（`<<->>` 是「有洁癖」的 `<<print>>`——输出前会把 HTML 特殊字符都消毒一遍，堪称防注入小卫士。）

### 语法

```SugarCube
<<- expression>>
```

### 参数

* **`expression`**：一个有效表达式。更多信息请参阅「表达式」。

### 示例

```SugarCube
/* 假设 $gold 为 5 */
你找到了 <<- $gold>> 金币。                  /* 输出：你找到了 5 金币。 */

/* 假设 $weight 为 74.6466266 */
你的体重是 <<- $weight.toFixed(2)>> 公斤。    /* 输出：你的体重是 74.65 公斤。 */
```

> **提示**：如果只需要打印一个 TwineScript 变量的值，直接写裸变量即可自动打印。
