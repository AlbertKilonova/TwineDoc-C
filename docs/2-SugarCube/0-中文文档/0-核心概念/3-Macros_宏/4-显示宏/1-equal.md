# Equal_赋值输出

输出给定表达式结果的字符串表示。此宏是 `<<print>>` 的别名。（`<<=>>` 是 `<<print>>` 的「缩写分身」——短小精悍，专治各种想少打字的场景。）

### 语法

```SugarCube
<<= expression>>
```

### 参数

* **`expression`**：一个有效表达式。更多信息请参阅「表达式」。

### 示例

```SugarCube
/* 假设 $gold 为 5 */
你找到了 <<= $gold>> 金币。                  /* 输出：你找到了 5 金币。 */

/* 假设 $weight 为 74.6466266 */
你的体重是 <<= $weight.toFixed(2)>> 公斤。    /* 输出：你的体重是 74.65 公斤。 */
```

> **提示**：如果只需要打印一个 TwineScript 变量的值，直接在段落文本里写裸变量即可，它会通过「裸变量标记」自动打印。
