# StoryTitle_故事标题

**Twine 2**：*未使用，非代码段落。* 故事标题是故事项目的一部分。

**Twine 1/Twee**：*必需。* 设置故事标题。（`StoryTitle` 是「身份证号」——存储 ID 的原料，不能乱填。）

> **警告**：故事标题用于创建存储 ID，用来存储所有玩家数据（临时和持久）。应为纯文本，不含任何代码、标记或宏。
> **提示**：若想设置包含代码、标记或宏的显示标题，请参阅 `StoryDisplayTitle` 代码段落。
