# Example Selectors_示例选择器

| 选择器 | 说明 |
| --- | --- |
| `html` | 文档元素。默认字体栈在此设置。活动段落的标签会被添加到其 `data-tags` 属性（参见：`段落转换`）。 |
| `body` | 页面主体。默认前景色和背景色在此设置。活动段落的标签会被添加到其 `data-tags` 属性和类（参见：`段落转换`）。 |
| `#story` | 选择故事元素。 |
| `#passages` | 选择包含段落元素的元素。所有创建的段落元素都是此元素的子元素。 |
| `.passage` | 选择段落元素。通常每回合只有一个这样的段落，但在段落导航期间可能会短暂地有两个——传入（即活动）和传出的段落。活动段落的名称会被添加为其 ID（参见：`段落转换`）。活动段落的标签会被添加到其 `data-tags` 属性和类（参见：`段落转换`）。 |
| `.passage a` | 选择段落元素内所有的 `<a>` 元素。 |
| `.passage a:hover` | 选择段落元素内正被悬停的 `<a>` 元素。 |
| `.passage a:active` | 选择段落元素内正被点击的 `<a>` 元素。 |
| `.passage .link-broken` | 选择段落元素内其段落不存在于故事中的所有内部链接元素。 |
| `.passage .link-disabled` | 选择段落元素内已被禁用的所有内部链接元素——例如，已被选择的 `<<choice>>` 宏链接。 |
| `.passage .link-external` | 选择段落元素内所有外部链接元素——例如，指向其他页面和网站的链接。 |
| `.passage .link-internal` | 选择段落元素内所有内部链接元素——例如，段落和宏链接。 |
| `.passage .link-visited`¹ | 选择段落元素内其段落位于进行中的故事历史中的所有内部链接元素——即，玩家以前去过的段落。 |
| `.passage .link-internal:not(.link-visited)`¹ | 选择段落元素内其段落不位于进行中的故事历史中的所有内部链接元素——即，玩家从未去过的段落。 |

¹ `.link-visited` 类默认未启用，有关更多信息，请参阅 `Config` API 的 `Config.addVisitedLinkClass` 属性。
