# Passage Conversions_段落转换

由段落名称和标签自动生成的 ID 和类会被规范化为全小写的 kebab case——这包括：移除不是字母数字、下划线、连字符、连字/长连字或空白的字符，然后将任何剩余的非字母数字字符替换为连字符（每组一个），最后将结果转换为小写。

### 段落名称

段落名称在其转换形式前加上 `passage-` 前缀，并根据段落的使用方式转换为 ID 和类——活动段落为 ID，被包含（通过 `<<include>>`）的段落为类。

例如，如果段落名称为 `Gone fishin'`，那么：

* 当作为活动段落时，它会成为 ID `passage-gone-fishin`（选择器：`#passage-gone-fishin`）。
* 当被包含时，它会成为类 `passage-gone-fishin`（选择器：`.passage-gone-fishin`）。

### 段落标签

显示段落时，其标签会被：

1. 作为 `data-tags` 属性中的空格分隔列表，添加到活动段落的容器元素、`<html>` 元素和 `<body>` 元素。
2. 作为类，添加到活动段落的容器元素和 `<body>` 元素。以下特殊标签被排除在此映射之外：

| 环境 | 被排除的标签 |
| --- | --- |
| Twine 2 | `debug`、`nobr`、`passage`、`widget`，以及任何以 `twine.` 开头的标签 |
| Twine 1/Twee | `debug`、`nobr`、`passage`、`script`、`stylesheet`、`widget`，以及任何以 `twine.` 开头的标签 |

例如，如果标签名称为 `Sector_42`，那么它既会成为 `data-tags` 属性成员 `Sector_42`（选择器：`[data-tags~="Sector_42"]`），也会成为类 `sector-42`（选择器：`.sector-42`）。
