# 指南：媒体段落

媒体段落只是将媒体嵌入项目的一种方式——带有特殊标签的段落，包含 Base64 编码媒体源的数据 URI。支持音频、图片、视频和 VTT（视频文本轨道）段落。

### 创建

#### 自动

支持自动创建媒体段落的编译器：

* [Tweego](http://www.motoslave.net/tweego/) 支持所有媒体段落。
* [Twine 1](http://www.twinery.org/) 支持图片段落。

#### 手动

> **警告（Twine 2）**：由于其设计中的各种限制，如果你使用 Twine 2 作为 IDE/编译器，则**强烈**建议你不要创建超过几个媒体段落，并且绝对不要使用大型源。
> 

要手动创建媒体段落：

1. 创建一个新段落，它将仅用作媒体段落——每个媒体源一个。
2. 用适当的媒体段落特殊标签（且仅该标签）标记它——见下文。
3. 将 Base64 编码的媒体源粘贴为段落的内容。

#### 媒体段落特殊标签

| 段落类型 | 标签 |
| --- | --- |
| 音频段落 | `Twine.audio` |
| 图片段落 | `Twine.image` |
| 视频段落 | `Twine.video` |
| VTT 段落 | `Twine.vtt` |

> **注意**：与所有特殊标签一样，媒体段落标签是区分大小写的，因此它们的拼写和大写必须*完全*与所示一致。
