# 指南：测试模式

### 简介

在测试模式下，SugarCube 会将所有宏以及一些非宏标记——例如，链接和图片标记——包裹在额外的 HTML 元素中，称为「调试视图」（简称「视图」）。视图使其关联的代码可见，从而提供屏幕上的反馈——它们也可以被悬停，这通常会暴露有关底层代码的额外信息。

> **注意**：在 ≥v2.23.0 的 SugarCube 版本中，调试界面提供了额外工具，即变量监视和任意历史导航。
> 

### 启用测试模式

#### 自动

在 Tweego 中，使用测试选项（`-t`、`--test`）。

在 Twine 2 中，从 *Stories* 屏幕点击故事齿轮菜单并选择 *Test Story* 菜单项；或从故事编辑器/地图屏幕点击底部栏右侧的 *Test* 菜单项。

在 Twine 1 中，右键单击一个段落并选择 *Test Play From Here* 上下文菜单项。

#### 手动

你可以通过将 `Config` 对象的 `debug` 属性设置为 `true` 来手动强制启用测试模式：

```plain
Config.debug = true; // 强制启用测试模式
```

### 调试栏（≥v2.23.0）

调试栏（页面右下角）允许你：监视故事和临时变量的值、切换调试视图、跳转到历史中的任何时刻/回合。

### 调试视图（≤v2.22.0）

调试视图本身可以通过 UI 栏顶部的 *Debug View* 按钮打开和关闭（默认：开）。

如果你已移除/隐藏 UI 栏，类似以下构造将允许你切换视图：

```plain
<<button "Toggle Debug Views">>`<<script>>`DebugView.toggle()<</script>><</button>>
```
