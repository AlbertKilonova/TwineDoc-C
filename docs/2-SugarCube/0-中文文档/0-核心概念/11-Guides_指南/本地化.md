# 指南：本地化

这是对 SugarCube 默认 UI 文本进行本地化的参考，一般来说，特别针对其 `l10nStrings` 对象。

> **注意**：如果你只是想下载现成的本地化，请参阅 locale 目录，其中的文件格式为 `xx-YY.js`——其中 `xx` 是标识语言的主代码（例如，`en`），`YY` 是指定国家变体的、大写的次代码（例如，`GB` 或 `US`）。
> 

### 翻译注意事项

默认替换字符串中使用的大写和标点是经过斟酌的，尤其是在错误和警告字符串中。你应该尽可能保持你的翻译相似。

替换模式的格式为 `{NAME}`——例如，`{textIdentity}`——其中 NAME 是 `l10nStrings` 对象中，或在少数情况下，在使用该字符串的本地提供的对象中，某个属性的名称——这些实例会被注释说明。

按惯例，以下划线开头的属性——例如，`_warningOutroDegraded`——用作模板，只被包含在其他本地化字符串中。

在使用中，替换模式会被递归替换，因此替换字符串可能包含其替换包含其他模式的模式。由于替换是递归的，必须注意确保不会创建无限循环——系统会检测到无限循环并抛出错误。

### 用法

字符串本地化对象（`l10nStrings`）上的属性应设置在你项目的 JavaScript 区（Twine 2：故事 JavaScript；Twine 1/Twee：一个 `script` 标签段落）中以覆盖默认值。

### 示例

```javascript
// 将项目报告的身份改为 'story'（默认：'game'）
l10nStrings.textIdentity = 'story';

// 将所有对话框确定按钮的文本改为 'Eeyup'（默认：'OK'）
l10nStrings.ok = 'Eeyup';

// 本地化重启对话框的标题（注意，机器翻译）
l10nStrings.restartTitle = 'Neustart';  // 德语 (de)
l10nStrings.restartTitle = 'Reiniciar'; // 西班牙语 (es)
```
