# 指南：TypeScript

SugarCube API 的 TypeScript 绑定可以在 [Definitely Typed](https://definitelytyped.org/) 包中找到：`@types/twine-sugarcube`。

要通过 NPM 安装该包，请使用以下命令：

```plain
npm install --save-dev @types/twine-sugarcube
```
