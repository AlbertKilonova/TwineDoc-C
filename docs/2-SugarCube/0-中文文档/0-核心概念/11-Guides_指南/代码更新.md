# 指南：代码更新

本指南记录了从旧版本升级 SugarCube 时需要了解的代码变更，按版本号分组（从 ≥2.37.0 到 ≥2.0.0，共 12 个条目）。

每个条目通常包含：

+ **对已有故事/项目的作者**：需要手动更新的破坏性变更。
+ **对（潜在）开发者的作者**：与代码相关的变更。

> **说明：** 由于各版本的更新说明内容较多且高度依赖具体版本，此处不逐一翻译。如需查阅某个具体版本（如「升级到 ≥2.37.0」）的详细变更，请参阅官方 SugarCube 文档的 *Code Updates* 指南页面。
