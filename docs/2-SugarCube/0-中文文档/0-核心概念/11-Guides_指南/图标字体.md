# 指南：图标字体

本指南是 SugarCube 所用图标字体 `sc-icons` 的参考，它基于 Font Awesome Free `7.1.0` 套件的 *Solid* 风格。

### 图标样式

任何图标样式规则都应使用以下 CSS 属性：

```css
cursor: pointer;
display: inline-block;
font-family: sc-icons !important;
font-size: 1em;
font-style: normal;
font-variant: normal;
font-weight: 900;
line-height: 1;
speak: never;
text-decoration: none;
text-rendering: auto;
text-transform: none;
user-select: none;
/* 浏览器前缀属性 */
-moz-osx-font-smoothing: grayscale;
-webkit-font-smoothing: antialiased;
```

### 图标引用

每个图标的十六进制引用 ID 列在其下方。引用 ID 的使用方式因使用位置而异：

+ **JavaScript 字符串：** 前缀 `\u`。例如，`\uf004`。
+ **CSS 样式：** 前缀 `\`。例如，`\f004`。
+ **HTML 实体：** 用 `&#x` 和 `;` 包裹。例如，`&#xf004;`。

> **说明：** 图标名称（`title`/`aria-label` 中的内容）为 Font Awesome 的规范标识符，按仓库惯例保留英文原文。
